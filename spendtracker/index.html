Subscriptions

Every flat-fee AI plan, with a Keep / Downgrade / Cancel verdict. Click a verdict to see the rule behind it.
How verdicts are decided
Rules run top to bottom; the first one that matches decides. No scoring model — v1 is deliberately simple so every verdict can be checked by hand.
  1. Linked to a data source (e.g. Claude Pro/Max ↔ Claude Code logs): zero usage in 30 days → Cancel; API-equivalent usage worth less than the monthly price → Downgrade; used on fewer than 8 of 30 days → Downgrade; otherwise Keep.
  2. No data source (ChatGPT Plus, Cursor Individual — no usage API exists): last used more than 30 days ago → Cancel; marked “rarely” → Downgrade; otherwise Keep.

Connections

Read-only admin keys pull daily cost and token usage. Keys are only ever used to read reports — never to make requests that spend money.
Not connectable yet
ChatGPT Plus has no usage API, and Cursor / GitHub Copilot usage APIs are gated to Teams/Business plans (PRD Phase 2). Track those as subscriptions with a last-used date instead. Gemini, DeepSeek and Mistral are unverified and deliberately not listed.
