ShiftDrop

Drag. Shift. Drop.

Converting a file shouldn't mean opening an app, hunting for an export menu, or uploading it to a sketchy website. Start dragging any file in Explorer, press Shift, and a wheel opens under your cursor. Drop the file on a format and the converted copy lands right next to the original.

Download for Windows

How it works

1

Start dragging

Pick up one or more files in Explorer or on the Desktop, like you're about to move them.

2

Press Shift

Still holding the mouse, tap Shift. The wheel opens under your cursor. Tap it again to switch to Tools.

3

Drop on a slice

The new file is saved beside the original. Drop in the centre to cancel; nothing is moved or overwritten.

Installing

  • Run ShiftDrop-Setup.exe. It installs for your Windows account only, so no admin password is needed, and adds Start menu and Desktop shortcuts.
  • Windows may show “Windows protected your PC” the first time, because ShiftDrop is a new, independent app without a paid code-signing certificate. Click More info → Run anyway.
  • ShiftDrop runs quietly in the system tray, near the clock. Right-click its icon to pause it, choose whether it starts with Windows, or quit.
  • Everything happens on your PC. Files are never uploaded anywhere and ShiftDrop doesn't connect to the internet.
  • Uninstall anytime from Settings → Apps → ShiftDrop.
