    Before the event / Setup

    Audio

    Every song has three 25-second hook versions, streamed from devindi.in. V1 is the main hook (it carries the title line); V2 and V3 are other places in the song where that part comes back. Next always plays V1.

    Nothing is saved on this device: the next song is fetched while the current one plays, so Next starts at once. The page needs internet during the game.

    Version 2 and 3 times come from automated repeat analysis and haven't been checked by ear. Use the hook editor to nudge any that miss.

    Hook editor

    Nudge where a version's 25 s hook starts (within a few seconds), preview it, then save on this device. Previews don't change the played list.
